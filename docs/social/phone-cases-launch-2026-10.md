**No domain in the captions.** Facebook allows links in only two posts per
month on pages without Meta One. September's two were used by the canvas and
Light & Silence posts, so "shopclaramendes.com" had to be removed ("Delete
link" in the composer strips only the domain). The page's website button
carries the shop link.

**Composer gotcha.** "Add photo/video" opens a native file picker. To attach
files through browser automation, patch `HTMLInputElement.prototype.click` so a
file input is appended to the DOM instead of opening the picker, then set its
files. The input usually appears on the second click of the button.
