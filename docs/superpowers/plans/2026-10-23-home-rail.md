# Home Rail Implementation Plan

> **For agentic workers:** the coordinator (Fable) runs three Opus implementer units in a worktree and commits one commit per unit. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shorten the homepage to hero → line rail → six priced curiosity tiles → trust strip → "The collection so far" → Letters from Nicosia → footer; bring the global header back once the hero has scrolled away; show a price chip on every curiosity tile in the buyer's currency.

**Architecture:** The rail is static data (`app/lib/lineRail.ts`, gated like the navigation) rendered by `app/components/LineRail.tsx` with its own CSS string. Tile prices come from one static `#graphql` query (`app/lib/homeTilePrices.ts`) keyed by a `priceHandle` on each `HERO_TILES` entry, reduced to labels with the card pricing rules. The route loader runs that query beside the lead-prints query; every other homepage query leaves with its band. The header returns by toggling `html.home-past-hero` from an IntersectionObserver on the hero's own glass pill; CSS shows the fixed `header.site-header` when the class is present.

**Tech Stack:** Hydrogen 2026.4 (React Router 7, React 18.3), TypeScript, CSS-in-JS strings per route/component, Node 24 `node --test` scripts in `scripts/*.node-test.mjs` that import `.ts` files directly (relative imports only).
