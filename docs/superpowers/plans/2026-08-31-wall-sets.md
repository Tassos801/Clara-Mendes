# Wall Sets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the seven curated three-print walls purchasable in one action on their existing landing pages, with a free generated hanging-guide PDF.

**Architecture:** A pure data/helpers module (`wallSets.ts`) drives a purchase component mounted by `collections.$handle.tsx` on the five capsule pages and two new gallery mix pages; a pdf-lib route serves the guide. No new Shopify products, no flags, no price changes.

**Tech Stack:** Hydrogen/React Router 7, Storefront API (aliased `product(handle:)`), pdf-lib (already bundled), node --test.

Spec: `docs/superpowers/specs/2026-08-31-gallery-walls-design.md`.

query WallSetProducts($h1: String!, $h2: String!, $h3: String!, $country: CountryCode, $language: LanguageCode)

  id handle title vendor productType tags

}
